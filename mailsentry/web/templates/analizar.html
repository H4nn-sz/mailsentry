¿Cómo obtengo el archivo o el código fuente?

Gmail
Abra el correo → menú ⋮ → Descargar mensaje (.eml) o Mostrar original.
Outlook web
Menú ⋯ → Ver → Ver detalles del mensaje y copie todo.
Outlook escritorio
Arrastre el correo a una carpeta (se guarda como .msg) o use Archivo → Guardar como.
Thunderbird
Clic derecho → Guardar como… (.eml).

Consejo: cree un buzón tipo reportes@ donde el personal reenvíe los correos dudosos como adjunto; MailSentry los analizará solo (ver Buzones).
