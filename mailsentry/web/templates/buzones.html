Gmail, Google Workspace y hosting (IMAP)

Agregue en config.toml:

[[buzones]]
nombre = "Gerencia"
conexion = "imap"
servidor = "imap.gmail.com"
usuario = "gerencia@suempresa.com.pe"
password_env = "MAILSENTRY_PASS_GERENCIA"

Y en el archivo .env la contraseña de aplicación: MAILSENTRY_PASS_GERENCIA=xxxx xxxx xxxx xxxx. En Gmail se crea en Cuenta de Google → Seguridad → Contraseñas de aplicaciones (requiere verificación en 2 pasos). Hostings con cPanel usan mail.sudominio.com y la contraseña normal del buzón.

Microsoft 365 / Outlook empresarial (Graph)

Microsoft ya no permite IMAP con contraseña. Registre una aplicación en Entra ID → Registros de aplicaciones, otorgue el permiso de aplicación Mail.Read (o Mail.ReadWrite para cuarentena) con consentimiento de administrador, cree un secreto y configure:

[[buzones]]
nombre = "Finanzas"
conexion = "graph"
usuario = "finanzas@suempresa.com"
tenant_id = "..."
client_id = "..."
secret_env = "MAILSENTRY_GRAPH_SECRET"
